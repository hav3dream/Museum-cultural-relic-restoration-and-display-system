## 4. Microsoft Project 录入步骤（待软件安装后执行）

1. **新建项目**：项目 → 项目信息 → 开始日期设为 `2026-11-09`；排定方法选"从项目开始日期排定"；
2. **设置日历**：项目 → 更改工作时间 → 对标准日历将 `2027-01-01` 设为非工作日（ Exceptions）；
3. **录入任务**：按第 2 节表格逐行录入任务名称；缩进/升级（Alt+Shift+→）建立 WBS 层级；工期列输入 `2d` 等；
4. **里程碑**：将 1.3、2.3、3.4、4.5、5.9、6.4、7.4、8.2 工期设为 `0d`（自动标记为里程碑）；
5. **紧前关系**：在前置任务列填入对应行号（如 4.5 的前置为 `4.3FS+0d;4.4FS+0d`），全部采用 FS 关系；
6. **资源**：在资源工作表建立 5 类资源（项目经理/前端/后端/AI算法/UI测试），并按表格"责任人"列分配；
7. **生成甘特图**：视图 → 甘特图；格式 → 临界任务着红色，检查关键路径是否与第 3.1 节一致；
8. **保存基准**：项目 → 设置基线（基线0），后续每周更新实际进度做挣值对比；
9. **导出**：文件 → 导出 PDF 甘特图 + 资源工作表，提交作业。
